## Wie man Codes einlöst und abgelaufene Drops vermeidet — Leitfaden für geleakte Codes

Um einen Code einzulösen, öffne Driving Empire, klicke auf das **Zahnrad-Symbol** in der oberen Ecke, um die Einstellungen zu öffnen, wechsle zum **Einstellungen-Tab** (nicht zum Audio- oder Grafik-Tab, was ein häufiger Fehlklick ist), tippe den Code genau so wie gepostet in das Einlöse-Feld und drücke Bestätigen. Belohnungen landen sofort in deinem Inventar, und Cash-Belohnungen erscheinen ohne separaten Einforderungs-Schritt in deinem verfügbaren Guthaben. Codes sind case-sensitive, also wird `call911` fehlschlagen, obwohl `CALL911` funktioniert. Community-Daten zeigen, dass Case-Unstimmigkeiten die häufigste Ursache für fehlgeschlagene Einlösungen sind.

| Schritt | Aktion | Häufiger Fehler |
|--------|--------|-----------------|
| 1 | Driving Empire öffnen | Der falschen Roblox-Experience beitreten |
| 2 | Auf das Zahnrad-Symbol klicken | Nach einem Button mit der Beschriftung "Codes" suchen |
| 3 | Zum Einstellungen-Tab wechseln | Auf dem Audio-Tab bleiben |
| 4 | Code einfügen oder eintippen | Den String versehentlich kleinschreiben |
| 5 | Bestätigen drücken | Das Menü schließen, bevor die Belohnung landet |

Das Einlöse-Feld ist nachsichtig bei Leerzeichen, also ist ein versehentliches Leerzeichen am Ende eines kopierten Strings normalerweise in Ordnung, aber gemischte Groß-/Kleinschreibung nicht. Wenn ein geleakter Code aus einem Screenshot unscharf ist und du nicht erkennen kannst, ob ein Buchstabe ein großes `I` oder kleines `l` ist, wechsle zu einer von Fans gepflegten Liste, die den verifizierten String in Klartext erneut einfügt.
